# 个人学术主页

这是一个纯静态单页网站，无需安装依赖或运行构建命令，可直接部署到 GitHub Pages。

## 修改内容

可在 `index.html` 中搜索并修改以下内容：

- `Devil`（英文品牌字样）
- `Your University`
- `hello@example.com`
- `github.com/ychq1314`
- `your-wechat-id`
- 专业、研究方向、简介、兴趣与教育经历

当前头像文件位于 `assets/avatar.jpg`。更换头像时覆盖该文件即可，建议继续使用接近竖版比例的 JPG 图片。

## GitHub Pages 部署

1. 将本目录内全部文件上传到 GitHub 仓库。
2. 进入仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 `main` 分支和 `/ (root)` 目录后保存。

站点只使用 HTML、CSS 与 JavaScript，不依赖后端服务。
